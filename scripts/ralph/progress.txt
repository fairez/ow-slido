## Codebase Patterns
- No zod here: config validation is hand-written `parse*Input(body, partial)` returning `{ok, value|error}` (see lib/polls.ts, lib/wordclouds.ts, lib/interaction-config.ts).
- New tables must cascade from `events`/`interactions` (`onDelete: "cascade"`) and get a cascade test.
- Full `npm test` takes ~100s; run it in the background and read the output file.

- Phase 3 source of truth: tasks/prd-slido-clone-phase3.md (permission matrix in Section 7, milestones in Section 10). From the first story on, no inline UI strings: use the i18n helper.
- Never call real Stripe, email or AI services from tests, e2e or Ralph runs: use BILLING_PROVIDER=mock, EMAIL_PROVIDER=log, AI_PROVIDER=mock.
- Do not touch databases other than ow_slido and ow_slido_test (a temporary database for a migration rehearsal is allowed if it is dropped afterwards).
